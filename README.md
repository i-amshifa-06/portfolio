# 🚀 Shifaul Kareem Portfolio

A modern, responsive, animated, and high-performance personal portfolio website built using **React 19, Vite, Tailwind CSS v4, Framer Motion, GSAP, and Lenis Smooth Scroll**.

This portfolio showcases my technical skills, projects, achievements, certifications, and experience as a **Cybersecurity Engineering Student** and **Full Stack Developer**.

Designed for recruiters, hiring managers, clients, and developers with a strong focus on performance, accessibility, SEO, and modern UI/UX.
